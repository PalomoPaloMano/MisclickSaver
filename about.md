# Misclick Saver

Si das un **misclick**, en vez de morir el mod hace que cuente como que lo hiciste bien y continúas el nivel.

## Cómo usar

1. Entra a cualquier nivel
2. Pausa el nivel
3. Arriba a la derecha verás el toggle **"Misclick Saver"**
4. Actívalo o desactívalo desde ahí

Cuando está activado y das un misclick → te salva y aparece el mensaje **"¡Lo hiciste bien!"**

## Aviso

Este mod es solo para **práctica y diversión**.  
No uses este mod en runs que quieras que cuenten como legítimas.
